# Specifikation: Saml opgavebeskrivelsen

**Status:** Gennemføres efter brugerens ønske

## Brugerhistorie

Som gruppemedlem vil jeg finde opgavebeskrivelsen og de supplerende spørgsmål samlet i én mappe, så jeg hurtigt kan slå kravene op.

## Acceptkriterier

1. De to originale PDF-filer ligger i `opgavebeskrivelse/` med deres oprindelige filnavne og indhold.
2. README linker til begge PDF-filer fra deres nye placering.
3. Arkitekturgennemgangen henviser til den nye mappe.
4. Spec Kit-zipfilen forbliver ignoreret.
